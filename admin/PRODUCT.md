# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Platform administrators managing artisan profiles, registering art pieces, and linking them to physical NFC tags for authenticity.

## Product Purpose

It securely links physical artisanal pieces to digital certificates of authenticity via NFC tags, ensuring provenance and preventing counterfeiting.

## Positioning

Secure physical-to-digital linkage via NFC tags for artisanal pieces, providing irrefutable proof of authenticity and provenance.

## Operating Context

Administrators use a web console to manage artisans, pieces, certificates, and NFC tags. The workflow involves registering physical artifacts and associating them with hardware NFC tags and digital records.

## Capabilities and Constraints

- Admin console with CRUD operations for artisans, pieces, NFC tags, certificates, media, and auditing.
- Must preserve the integration with NFC hardware workflows.
- Web platform built with React, Vite, and Tailwind CSS.

## Brand Commitments

- "botanica" color palette (e.g., botanica-jade, botanica-negro, botanica-grafito, botanica-hueso, botanica-gris).
- Current navigation structure.
- Professional, trustworthy interface for management and cataloging.

## Evidence on Hand

- Existing Vite + React application.
- Authentication flow.
- Admin layout with side navigation.
